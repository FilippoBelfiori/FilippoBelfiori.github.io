Based on a YouTube lecture by Hunter Spink. These are informal introductory notes; we do not worry about the details of model theory but focus on the ideas and tools usable in algebraic geometry.

I. Motivation

Algebraic geometry studies sets you can write down using $+$ and $\times$: from these two operations you get all polynomials, and the collection $\{+, \times\}$ is naturally associated to fields.

Question. What if I look at sets defined not just with polynomials, but also using $\sin$, $\cos$, $\exp$, $\log$, ...?

Idea. Model theorists identified the weakest condition on a collection of functions $\mathcal{F}$ that prevents you from creating "bad" sets when you add those functions to your language. "Bad" means: a Cantor set, infinitely many connected components, or a set that is not a piecewise differentiable manifold. The key insight is that the right condition ensures nothing bad can be created at all.

Grothendieck was the first to ask: "Why can't I use $\exp$, $\sin$, $\cos$, ... in geometry?" Nowadays this question has many answers, and o-minimality provides the framework.

II. Definable Sets

The language

Fix a collection of functions $\mathcal{F} = \{+, \times, f_1, \ldots, f_k\}$ where each $f_i : \mathbb{R}^{n_i} \to \mathbb{R}$. Taking $\mathcal{F} = \{+, \times\}$ gives polynomials; in general $\mathcal{F}$ can be any collection.

Remark. The quantifiers $\exists$ and $\forall$ allow us to express the concepts of continuity and differentiability (think of the $\varepsilon$-$\delta$ definition from analysis).

Definition

A set $S \subset \mathbb{R}^n$ is $\mathcal{F}$-definable if there exists a first-order formula $\phi(x_1, \ldots, x_n)$ such that

$$S = S_\phi := \{(x_1, \ldots, x_n) \mid \phi(x_1, \ldots, x_n) \text{ is true}\}.$$

A formula $\phi$ is built from the following ingredients:

Terms (the "nouns"): constants, parentheses, variables, and arbitrary compositions of functions in $\mathcal{F}$, e.g. $f_1(x_2 + f_2(x_1), \sqrt{2})$.

Atomic predicates: $<$, $=$, $>$. Combined with terms, these produce atomic statements such as $f_1(x_2 + f_2(x_1), \sqrt{2}) > f_3(0)$.

Logical connectives: $\lnot$, $\lor$, $\land$, $\to$, $\leftrightarrow$, etc., which combine atomic statements, e.g. $f_1(\cdots) > f_3(0)$ or $f_4(x_1) = f_5(x_2)$.

Quantifiers: $\exists x \in \mathbb{R}$ and $\forall x \in \mathbb{R}$, e.g.:

$$\exists\, z \in \mathbb{R} \text{ s.t. } \bigl(f_1(x_2 + f_2(x_1), \sqrt{2}) > f_3(0)\bigr) \text{ or } \bigl(f_4(x_1, z) = f_5(z)\bigr).$$

Example. With $\mathcal{F} = \{+, \times\}$, the unit circle is definable: it is $S_\phi$ for the formula $\phi(x,y) \equiv (x^2 + y^2 = 1)$.

Examples with $\mathcal{F} = \{+, \times, \exp_\mathbb{R}\}$

The following are all $\mathcal{F}$-definable sets, illustrating how quantifiers let us build new functions from $\exp$ alone:

Graph of a composition:

$$\{(x,y) \in \mathbb{R}^2 \mid y = e^{e^x(x^2+5x+6)}\} \subset \mathbb{R}^2.$$

A level set with inequality (using $\leq$, which we can write as $< $ or $=$):

$$\{(x,y) \in \mathbb{R}^2 \mid e^x + e^y \leq 4\} \subset \mathbb{R}^2, \qquad \text{formula: } e^x + e^y = 4 \text{ or } e^x + e^y < 4.$$

An image (using $\exists$):

$$\mathrm{Im}(e^{yz})\big|_{y + e^z = 4} \subset \mathbb{R}, \qquad \text{formula: } \exists\, y, z \in \mathbb{R} \text{ s.t. } y + e^z = 4 \text{ and } x = e^{yz}.$$

Graph of $e^{(\log x)^2}$ (recovering $\log$ via $\exists$):

$$\{(x,y) \in \mathbb{R}^2 \mid y = e^{(\log x)^2}\} \subset \mathbb{R}^2, \qquad \text{formula: } \exists\, z \in \mathbb{R} \text{ s.t. } (e^z = x \text{ and } y = e^{z^2}).$$

Using $\exists z$ with $e^z = x$ is how we define $z = \log x$ without adding $\log$ as a primitive.

Remark. The definable sets for $\mathcal{F} = \{\exp\}$ and $\mathcal{F} = \{\exp, \log\}$ are identical: $\log$ is already definable from $\exp$ via a quantifier.

Power functions are now available: $\{(x,y) \mid y = 5x^\pi\}$ is definable because $5x^\pi = 5 \cdot e^{\pi \log x}$, a composition of $\exp$, $\log$, and constants.

III. O-minimality

Definition. $\mathcal{F}$ is o-minimal if every $\mathcal{F}$-definable subset of $\mathbb{R}$ is a finite union of points and intervals (possibly open, closed, or unbounded on either end).

The key word is finite. This is a condition only on subsets of $\mathbb{R}$, but as we will see it has powerful consequences in all dimensions.

What does this constraint rule out?

Example: $\mathcal{F} = \{+, \times, \sin\}$ is NOT o-minimal. The set $S_{\sin(x)=0} = \pi\mathbb{Z} \subset \mathbb{R}$ is definable (formula: $\sin(x) = 0$), but it is not a finite union of points and intervals. Saying "$\sin$ is not o-minimal" is equivalent to saying: this structure cannot talk about periodic sets without running into infinitely many connected components.

Example: $\mathcal{F} = \{+, \times\}$ IS o-minimal — this is the Tarski–Seidenberg theorem. For every formula $\phi$, there exists a quantifier-free formula $\psi$ (not involving $\exists x \in \mathbb{R}$ or $\forall x \in \mathbb{R}$) such that $S_\phi = S_\psi$. This is quantifier elimination for real closed fields, and it implies that every definable subset of $\mathbb{R}$ is a finite union of points and open intervals.

As an example of quantifier elimination: $S_{(\exists\, y, z \mid (y-1)^2 + z^2 = x)} = \mathrm{Im}((y-1)^2 + z^2) = (0, +\infty) = S_{0 < x}$.

Known o-minimal structures

$\mathcal{F} = \{+, \times, \exp_\mathbb{R}\}$ is o-minimal — this is a deep theorem requiring hard analysis and model theory.

$\mathcal{F} = \{+, \times, \exp_\mathbb{R},\, \sin\big|_{[0,2\pi]},\, \cos\big|_{[0,2\pi]}\}$ is o-minimal — restricting $\sin$ and $\cos$ to a compact interval removes the periodicity that caused problems above.

The largest known o-minimal structure is the "Pfaffian closure" or "restricted analytic functions."

IV. The Uniform Boundedness Theorem

The fundamental structural result of o-minimality is the following.

Theorem (Uniform Boundedness / Cell Decomposition). If $\mathcal{F}$ is o-minimal, then every definable set $S_\phi \subset \mathbb{R}^n$ is a finite Boolean combination of connected differentiable manifolds. Moreover, every $S_\phi$ is homeomorphic to a union of relative interiors of simplices in a finite simplicial complex — so no bad topology is possible.

The deeper "magic" statement is:

For a fixed formula complexity $\mathrm{comp}(\phi) = $ (number of symbols in $\phi$, where constants count as 1 symbol), only finitely many homeomorphism types of simplicial complexes occur. In other words, the topology of $S_\phi$ is bounded purely by the length of the formula defining it, independently of the specific constants appearing.

Corollary 1. Every definable function is piecewise differentiable.

Corollary 2. If $S_\phi$ is a finite set of points, then $|S_\phi|$ is bounded above by a function of $\mathrm{comp}(\phi)$ alone. This corollary is key for applications.

V. First Application: Khovanskii's Fewnomial Theorem

Setup

A polynomial in $m$ variables is written as:

$$f(x_1, \ldots, x_m) = \sum_{(i_1, \ldots, i_m) \in \mathrm{Supp}(f)} a_{i_1 \cdots i_m}\, x_1^{i_1} \cdots x_m^{i_m},$$

where $\mathrm{Supp}(f)$ denotes the set of multi-indices of non-zero coefficients (the support).

Consider a system $\{f_1 = 0, \ldots, f_n = 0\}$ in $(\mathbb{R}_{>0})^n$ with finitely many solutions.

Bézout's theorem gives a bound on the number of solutions in terms of the degrees: $\#\text{solutions} \leq \prod_i \deg(f_i)$. But if the exponents are very large (high degree), this bound becomes terrible.

Claim: there exists a bound independent of the exponents, depending only on the sizes of the supports.

Theorem (Khovanskii's Fewnomial Theorem). If the system $\{f_1 = 0, \ldots, f_n = 0\}$ has finitely many solutions in $(\mathbb{R}_{>0})^n$, then the number of solutions is bounded by a function of $|\mathrm{Supp}(f_1)|, \ldots, |\mathrm{Supp}(f_n)|$ alone.

Proof via o-minimality

The key observation is how to encode the system without increasing the number of symbols as the exponents grow. Note that:

$$x^2 + xy = e^{2\log x} + e^{\log x + \log y}, \qquad x^n + xyz = e^{n\log x} + e^{\log x + \log y + \log z}.$$

Even replacing 2 by $n$ (a large exponent), the number of symbols in the formula does not change — the exponent $n$ appears as a constant, which counts as 1 symbol. Rewriting the system using $\exp$ and $\log$:

$$\phi(x_1, \ldots, x_m)\colon \sum_{(i_1,\ldots,i_m)\in\mathrm{Supp}(f_1)} a_{i_1\cdots i_m}\, \exp(i_1\log x_1 + \cdots + i_m\log x_m) = 0 \quad \land \quad \cdots$$

The complexity $\mathrm{comp}(\phi)$ depends only on the number of non-zero coefficients $|\mathrm{Supp}(f_j)|$, not on the size of the exponents. By Corollary 2 above (and the fact that $\mathcal{F} = \{+, \times, \exp\}$ is o-minimal), the number of solutions is bounded by a function of $\mathrm{comp}(\phi)$, which is a function of the support sizes. $\square$

VI. Second Application: Pila–Wilkie Point Counting

Setup

A semi-algebraic set in $\mathbb{R}^n$ is defined by polynomial equations and inequalities (e.g. curves, parabolas, discs). Semi-algebraic sets can contain many rational points: for example, $\{(x,y) \mid y = x^2\} \cap \mathbb{Q}^2$ is infinite.

Surprisingly, transcendental sets contain very few rational points.

Definition. For $S \subset \mathbb{R}^n$, the transcendental part of $S$ is:

$$S_{\mathrm{tr}} := S \setminus \bigcup\{V \mid V \subset S \text{ semi-algebraic},\, \dim V \geq 1\},$$

i.e. we remove all positive-dimensional semi-algebraic subsets contained in $S$ — everything that is not "algebraic geometry."

Define the height of a rational point $(a_1/b_1, \ldots, a_n/b_n) \in \mathbb{Q}^n$ (with $a_i, b_i \in \mathbb{Z}$) to be $\max(|a_i|, |b_i|)$.

Theorem (Pila–Wilkie). Let $S \subset \mathbb{R}^n$ be definable over an o-minimal structure $\mathcal{F} = \{+, \times, \ldots\}$. Then

$$\#\!\left\{\left(\tfrac{a_1}{b_1}, \ldots, \tfrac{a_n}{b_n}\right) \in S_{\mathrm{tr}} \cap \mathbb{Q}^n \;\middle|\; |a_1|, \ldots, |a_n|, |b_1|, \ldots, |b_n| \leq N\right\}$$

grows slower than $N^\varepsilon$ for any $\varepsilon > 0$.

In other words, the count grows slower than any polynomial in $N$ (slower than $N^{1/2}$, $N^{1/3}$, ...). The only hypothesis needed is that $S$ is definable!

The o-minimality restricts the possible number of rational points in the transcendental part. This is a shocking theorem.

VII. Application of Pila–Wilkie: Multiplicative Manin–Mumford

Statement

Let $f(x, y) = \sum a_{jk} x^j y^k$ be an irreducible polynomial with $|\mathrm{Supp}(f)| \geq 3$.

Theorem (Multiplicative Manin–Mumford). There are only finitely many solutions to $f(x, y) = 0$ with $x, y$ roots of unity.

Why is this surprising? Each individual root of unity $e^{2\pi i/n}$ is algebraic, but there is no way to put all of them together into a single algebraic family — the "reason" for the finiteness is transcendental.

Reformulation

For $z \in \mathbb{C}$, set $\omega(z) = e^{2\pi i z}$. The theorem is equivalent to: there are finitely many solutions $(s,t) \in (\mathbb{Q} \cap [0,1])^2$ to $f(\omega(s), \omega(t)) = 0$.

Proof via Pila–Wilkie

Step 1: The structure $\mathcal{F} = \{+, \times, \exp_\mathbb{R}, \cos(2\pi x)|_{[0,1]}, \sin(2\pi x)|_{[0,1]}\}$ is o-minimal.

Step 2: Define the surface. Note that $\omega(a+ib) = e^{-b}\cos(2\pi a) + ie^{-b}\sin(2\pi a)$, so

$$S := \{(s,t) \in \mathbb{C}^2 \cong \mathbb{R}^4 \mid 0 \leq \mathrm{Re}(s), \mathrm{Re}(t) \leq 1 \text{ and } f(\omega(s), \omega(t)) = 0\}$$

is a definable set over $\mathcal{F}$ (and a complex surface), sitting inside $(\mathbb{R} + i\mathbb{R})^2 \cong \mathbb{R}^4$.

Step 3: The transcendental part. One shows that $S = S_{\mathrm{tr}}$, i.e. $S$ contains no positive-dimensional semi-algebraic subsets (intuitively: $f$ is irreducible and transcendental, so its zero set on $[0,1]^2$ cannot contain any algebraic curve). This uses the irreducibility of $f$ and the condition $|\mathrm{Supp}(f)| \geq 3$.

Step 4: Apply Pila–Wilkie. The rational points of $S \cap \mathbb{Q}^4$ of height $\leq N$ correspond precisely to solutions $(\omega(p/q), \omega(r/s))$ with $q, s \leq N$ — i.e., roots of unity of order $\leq N$. By Pila–Wilkie, their count is $O(N^\varepsilon)$ for any $\varepsilon > 0$.

Step 5: Contradiction via Galois. Suppose $f(\omega(3/124), \omega(a/b)) = 0$ with $124 \nmid b$. Applying Galois automorphisms (which permute the roots of unity), we get solutions $(\omega(i/124), \omega(a'/b))$ for all $1 \leq i \leq 124$ with $\gcd(i, 124) = 1$. There are at least $\sqrt{124}$ such values, giving at least $\sqrt{124}$ points on $S$ of height $\leq 124$. More generally, if we had infinitely many root-of-unity solutions as $N \to \infty$, the count would grow at least polynomially (like $\sqrt{N}$), contradicting the Pila–Wilkie bound of $O(N^\varepsilon)$.

Therefore there are only finitely many root-of-unity solutions to $f(x,y) = 0$. $\square$
